# Neural Network Verification Benchmarking

This project compares Gurobi-based neural network verification with α,β-CROWN on a supported subset of VNN-COMP 2026 benchmarks.

## Language

**Gurobi**:
The optimization solver used to solve optimization encodings of neural network verification problems.

**α,β-CROWN (ABC)**:
The neural network verifier used as the comparison baseline for this study. ABC is the project's shorthand for α,β-CROWN.

**Optimization encoding**:
A mathematical optimization representation of a neural network verification problem, including the network and the property being checked.
